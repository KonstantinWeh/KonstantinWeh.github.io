[Auto]Stitching Photo Mosaics

Overview

Project 3: [Auto]Stitching Photo Mosaics

This project is all about stitching together many photographs to create larger composite images. The project involves shooting photographs with projective transformations, recovering homographies between image pairs, warping images for alignment, and blending them into seamless mosaics.

The project is divided into four main tasks:

  • A.1: Shoot the Pictures - Capture photographs with projective transformations
  • A.2: Recover Homographies - Compute transformation matrices between image pairs
  • A.3: Warp the Images - Implement image warping with different interpolation methods
  • A.4: Blend the Images into a Mosaic - Create seamless composite images
Task A.1

Shoot the Pictures

Shoot two or more photographs so that the transforms between them are projective (a.k.a. perspective). The most common way is to fix the center of projection (COP) and rotate your camera while capturing photos.

Deliverables:

Task A.2

Recover Homographies

Before you can warp your images into alignment, you need to recover the parameters of the transformation between each pair of images. In our case, the transformation is a homography: p'=Hp, where H is a 3x3 matrix with 8 degrees of freedom.

Display system of equations

For one correspondence pair (x,y) → (u,v), the system of equations is:

[0   0   0   x   y   1   -vx   -vy]

Where:

  • a₁ᵀ = [x y 1 0 0 0 -ux -uy]
  • a₂ᵀ = [0 0 0 x y 1 -vx -vy]
  • b₁ = u
  • b₂ = v

This gives us 2 equations for 8 unknowns. With n correspondence pairs, we get 2n equations, forming an overdetermined system that can be solved using least squares when n ≥ 4.

This is exactly what we discussed in class. The total system of equations can be found below in python code.

Implement computeH(im1_pts, im2_pts) function

Write a function of the form:

H = computeH(im1_pts, im2_pts)

where im1_pts and im2_pts are n-by-2 matrices holding the (x,y) locations of n point correspondences from the two images and H is the recovered 3x3 homography matrix.

Implementation: The function constructs the matrix A (2n×8) and vector b (2n×1) as shown above, then uses least squares to solve Ah=b. The solution h contains the 8 homography parameters, which are reshaped into the 3×3 matrix H.


              # Construct matrix A using numpy indexing
              A[0::2, 0:3] = np.stack([x, y, np.ones(n)], axis=1)  # First row of each pair
              A[1::2, 3:6] = np.stack([x, y, np.ones(n)], axis=1)  # Second row of each pair
              A[0::2, 6]   = -u * x                                # -ux terms
              A[0::2, 7]   = -u * y                                # -uy terms
              A[1::2, 6]   = -v * x                                # -vx terms
              A[1::2, 7]   = -v * y                                # -vy terms

              # Construct vector b
              b[0::2] = u  # u coordinates
              b[1::2] = v  # v coordinates

              # Solve using least squares
              h, residuals, rank, s = np.linalg.lstsq(A, b, rcond=None)

Task A.3

Warp the Images

Implement warpImageNearestNeighbor(im, H) and warpImageBilinear(im, H) using inverse warping

The two different interpolation methods differ in how they pick the pixel values for the output image. Nearest Neighbor Interpolation rounds the coordinates to the nearest pixel value, while Bilinear Interpolation uses a weighted average of the four neighboring pixels.

In code, this difference is between these lines:


              xi = np.rint(x).astype(np.int64)
              yi = np.rint(y).astype(np.int64)

              flat_out[inbounds, :] = im[yi[inbounds], xi[inbounds], :]

and


              x0 = np.floor(x[inbounds]).astype(np.int64)
              y0 = np.floor(y[inbounds]).astype(np.int64)
              x1 = np.minimum(x0 + 1, w_in - 1)
              y1 = np.minimum(y0 + 1, h_in - 1)

              wa = (x1 - x[inbounds]) * (y1 - y[inbounds])
              wb = (x[inbounds] - x0) * (y1 - y[inbounds])
              wc = (x1 - x[inbounds]) * (y[inbounds] - y0)
              wd = (x[inbounds] - x0) * (y[inbounds] - y0)

              flat_out[inbounds, :] =  (wa[:, np.newaxis] * im[y0, x0, :] + 
                                        wb[:, np.newaxis] * im[y0, x1, :] + 
                                        wc[:, np.newaxis] * im[y1, x0, :] +

Show comparisons between interpolation methods

Discuss trade-offs between speed and quality

Nearest neighbor interpolation is significantly faster than bilinear interpolation, as shown by the timing results above (9.49s vs. 27.88s, i.e. nearest neighbor is 2.94x faster). On a large scale, both methods produce similar-looking results, and the differences may not be immediately obvious. However, when you zoom in (e.g. on the twigs and rails in the zoomed-in comparison), the quality improvement from bilinear interpolation becomes quite noticeable: edges are smoother and there are fewer blocky artifacts compared to nearest neighbor. This makes bilinear interpolation preferable when image quality is important, especially in areas with fine details, while nearest neighbor is a good choice when speed is the priority.
