CS180 Project 3 (Part 1)

Python files for CS180 Project 3, including data preprocessing, implementation, experiments, and results.

File overview:
- main_part2.py: Core functionality for automatic stiching
- main.py: All core functionality and script to blend images (helper functions for automatic stiching)
- get_correspondences: Script to retrieve matching points in two images
- interpolation_comparision.py: Script to compare runtime and quality of the two warping functions
- produce_rectified_ims.py: Script to generate the rectified CalID and Kitchen drawer
