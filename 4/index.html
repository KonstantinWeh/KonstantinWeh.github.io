Part 1

Fit a Neural Field to a 2D Image

Model Architecture Report

  • Layers: 1 positional encoding module (PosEnc, L=10);
    4-layer MLP:
        Linear(pe_dim→256) → ReLU,
        Linear(256→256) → ReLU,
        Linear(256→256) → ReLU,
        Linear(256→3) → Sigmoid
  • Width: 256 neurons per hidden layer
  • Learning Rate: 1e-2 (Adam optimizer)
  • Other Details:
    • Activation: ReLU (hidden layers), Sigmoid (output layer)
    • Positional Encoding: L=10 (uses 10 frequency bands as input PE)
    • pe_dim = 2 input + 2*(2*L) = 42
    • Output: 3 channels (RGB), normalized [0,1]

Part 2

Fit a Neural Radiance Field from Multi-view Images

Implementation Notes

Part 2.1

Camera to World Coordinate Conversion

The camera to world coordinate conversion is implemented in the transform_c2w function in the nerf_multi_view.py file. The function takes a camera to world coordinate matrix and a point in the camera coordinate system and returns the point in the world coordinate system. It appends a [1] to the point and then multiplies it by the camera to world coordinate matrix using einsum to get the point in the world coordinate system.

Pixel to Camera Coordinate Conversion

The pixel to camera coordinate conversion is implemented in the pixel_to_camera function in the nerf_multi_view.py file. It multiplies the point by the inverse of the camera intrinsics matrix using einsum to get the u, v point in the camera coordinate system.

Pixel to Ray Conversion

The pixel to ray conversion is implemented in the pixel_to_ray function in the nerf_multi_view.py file. It implements the conversion using the given formula.

Part 2.2

Sampling Rays from Images and Sampling Points Along Rays

The sampling rays from images is implemented in the sample_random_rays function in the nerf_multi_view.py file. It samples rays from the images using the pixel_to_ray function and returns the origin and direction along with the colors and indices. The origins and directions are used in the sample_points_along_rays function to generate the points along the rays (64 samples per ray starting from 2.0 to 6.0 in the near and far plane).

Part 2.3

RaysData Class

The RaysData class is implemented in the nerf_multi_view.py file. It contains the images, camera intrinsics matrix and camera to world coordinate matrices. It also contains the function to sample rays from the images.

Part 2.4

Neural Field Training

The neural field training is implemented in the train_nerf function in the nerf_neural_field_3d.py file. It trains the neural field that is provided in the task description using the data sampled by the RaysData class. It can save and load checkpoints to resume training.

Part 2.5

Volume Rendering

The volume rendering step is implemented in the volrend function in volume_rendering.py. This function computes opacities and transmittance along sampled points on rays. It combines them with the predicted colors to calculate the final rendered color using the provided formula.
