Training a Flow Matching Model

1.2 Visualizing the Noising Process (UNet Denoiser Training)

To train the denoiser network noisy images are created by adding Gaussian noise to clean MNIST digits using various noise levels ( σ).
Below the output of the noising process for a single MNIST digit with increasing values of σ \in [0.0, 0.2, 0.4, 0.5, 0.6, 0.8, 1.0] is visualized. As σ increases, the digit becomes more and more corrupted by noise, making the restoration problem harder.

1.2.1 Training

The objective is to train a denoiser to denoise noisy image xnoisy = x + σε with noise σε applied to a clean image x.

Dataset and dataloader: The MNIST dataset via torchvision.datasets.MNIST is used. Only the training set is used, the dataset is shuffled before creating the dataloader, and a batch size of 256. The dataset is trained over for 5 epochs. The image batches are noised when fetched from the dataloader so that in every epoch the network sees new noised images due to random σ, improving generalization.

Model: The UNet architecture defined in section 1.1 with hidden dimension D = 128 is used.

Optimizer: The Adam optimizer with a learning rate of 1e-4 is used.

1.2.3 Denoising Pure Noise

To make denoising a generative task, the denoiser is trained to denoise pure random Gaussian noise xnoisy = ε where ε ~ N(0, I), effectively starting from a blank canvas and denoising it to generate a clean image. The same training process as in section 1.2.1 is repeated, but with pure noise as input, training for 5 epochs.

Patterns observed: The generated outputs from pure noise tend to converge toward blurry, averaged versions of the training digits. Rather than generating distinct, sharp digits, the model produces images that resemble a "centroid" or average of all training examples.

Explanation: With MSE loss, the model learns to predict the point that minimizes the sum of squared distances to all training examples. This is equivalent to predicting the mean of the training distribution. In the context of MNIST digits, this means the model learns to output a blurred average that minimizes the expected squared error across all possible digits (0-9). The model cannot generate specific digits because it has no conditioning signal to distinguish between different classes. It can only predict the optimal "centroid" that minimizes loss across all training images.

2.2 Training the UNet

Training our time-conditioned UNet is now pretty easy. Basically, we pick a random image from the training set, a random timestep t, add noise to x_0 to get x_t, and train the denoiser to predict the flow at t. We repeat this for different images and different timesteps until the model converges and we are happy.

Dataset and dataloader: The MNIST dataset via torchvision.datasets.MNIST is used. Training is performed only on the training set. The dataset is shuffled before creating the dataloader. A batch size of 64 is used. As shown in Algorithm B.1, image batches are noised when fetched from the dataloader.

Model: The time-conditioned UNet architecture defined in section 2.1 is used with recommended hidden dimension D = 64. The conditioning signal t is injected into the UNet following the diagram and pseudocode. The timestep t is normalized before embedding it.

Optimizer: The Adam optimizer with an initial learning rate of 1e-2 is used. An exponential learning rate decay scheduler with a gamma of 0.999 is implemented using torch.optim.lr_scheduler.ExponentialLR(...). The scheduler is stepped after every epoch.

Removing the Learning Rate Scheduler

The exponential learning rate scheduler adds complexity to the training process. To simplify the training setup while maintaining performance, we removed the scheduler and compensated by adjusting the initial learning rate and training dynamics.

What I did to compensate: Instead of using an exponential decay scheduler (gamma = 0.999), a constant learning rate was maintained throughout training. To ensure similar performance, the initial learning rate was set to 1e-2 to match the effective learning rate that the scheduler would have provided during the later stages of training.
